# 🧠 Basic Coding Workshop

Struggling with coding challenges? You're not alone — and we've got your back!

We're excited to invite you to our **Basic Coding Workshop**, specially designed to help strengthen essential programming skills and boost your confidence.

Whether you're just getting started or aiming to sharpen your practical coding abilities for more advanced EE modules, these hands-on sessions are the perfect opportunity to bridge the gap and level up.

> 💻 **Important:** Please bring your personal laptop to the classroom for live coding activities.

---

## ⚠️ Pre-Session Setup (Important!)

To participate fully in the hands-on activities, students are recommended to install the following software beforehand:

1. **Visual Studio Code (VS Code) and/or PyCharm**
   - Used for writing, running, and debugging code.

2. **Anaconda**
   - Used for managing Python environments and packages.
   - Anaconda also provides access to Jupyter Notebook.

3. **GitHub Copilot**
   - Install GitHub Copilot in VS Code or PyCharm for the AI-assisted coding activities in Session II.

Please check that the required software can be opened and used before attending the workshop.

## 🔹 Session I: Essential Tools for Modern Programming

- 📅 **Date:** 12 August
- 🕑 **Time:** 2:00 PM – 5:00 PM
- 📍 **Venue:** EA-02-11
- 👥 **Capacity:** 90
- 🎯 **Objective:** Helps bridge the gap from CS1010E to EE2211 and EE2213

### Topics & Instructors

1. **Foundations of Programming Tools and Environments**

   **Instructor:** Neil Banerjee

   - Filesystem basics on Windows, Mac, and Linux
   - Text editors vs IDEs, such as VS Code and PyCharm
   - How code runs: compiling vs interpreting
   - Basic command-line tools, including `cd`, `ls`, `cp`, and `mv`

2. **How to Manage Packages in Anaconda**

   **Instructor:** Theivendiram Pranavan

   - Learn how to efficiently manage Python environments and dependencies using Anaconda
   - Participate in hands-on coding activities

3. **Python Clinic**

   **Instructor:** Du Yutong

   - Anaconda
   - Jupyter Notebook
   - Integrated development environments
   - Assignment guidance
   - Installing Python without Anaconda

### Learning Outcomes

By the end of Session I, students should be able to:

- Clarify the functions of programming environments
- Understand package management for Python
- Develop confidence in programming and code management for EE courses

## 🔹 Session II: Programming Infrastructure and Debugging Skills

- 📅 **Date:** 14 August
- 🕑 **Time:** 2:00 PM – 5:00 PM
- 📍 **Venue:** E1-06-08
- 👥 **Capacity:** 80
- 🎯 **Objective:** Helps bridge the gap from CS1010E to EE2028 and EE2211

### Topics & Instructors

1. **Errors Are Your Friend, Not Your Enemy**

   **Instructors:** Ni Qingqing and Neil Banerjee

   - How to read and understand error messages
   - Common Python errors
   - Using errors to guide incremental code development
   - Live coding demonstrations

2. **Overview of Microsoft Copilot**

   **Instructor:** Shao Yurui

   - Introduction to Copilot features
   - Hands-on coding activities with AI-assisted development

3. **Build Your Own AI Coding Agent with GitHub Copilot**

   **Instructor:** Yu Juezhao

   - Build a minimal AI coding agent using GitHub Copilot
   - Learn how modern coding agents understand repositories, plan changes, edit code, and verify their work
   - Develop practical AI software engineering skills for collaborating effectively with coding agents

### Learning Outcomes

By the end of Session II, students should be able to:

- Analyse programming error messages
- Apply essential debugging and development tools in programming
- Apply AI-assisted tools during the programming process
